# Vault-Tec Enterprise Suite™ - Terminal Edition

*"Building Tomorrow's Business Solutions... Yesterday's Way"*

A **real terminal interface** for the Monk API, bringing authentic pre-war corporate terminal experience to vault management.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Static demo (shows layout, then exits)
npm run demo

# Interactive version (responds to keyboard, exits after)
npm run interactive

# Development mode (auto-restart on file changes)
npm run watch
```

## ⌨️ Keyboard Navigation

### **Module Navigation:**
- **F3** or **`** - Cycle through modules
- **1-6** - Jump directly to specific modules
- **ESC** - Return to Overseer Console
- **F10** - Emergency exit

### **System Functions:**
- **F1** - Toggle help system
- All **F1-F12** keys work perfectly (no browser conflicts!)

## 🖥️ Terminal Features

### **Full Terminal Integration:**
- **Responsive layout** - Adapts to any terminal size
- **Function key bars** - Classic terminal software styling
- **Perfect ASCII art** - Native terminal font rendering
- **ANSI colors** - Authentic green phosphor terminal colors
- **Keyboard-only control** - No mouse required

### **Authentic Experience:**
- **Real terminal application** - Not browser simulation
